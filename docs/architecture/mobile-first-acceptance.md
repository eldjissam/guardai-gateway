# Mobile-first acceptance criteria

- Support 320 CSS pixels width without horizontal page scrolling.
- Use a touch drawer for navigation on mobile.
- Use a collapsible sidebar on tablet and desktop.
- Keep the composer visible and reachable above device safe areas.
- Ensure modal content fits within short phone viewports and can scroll.
- All interactive controls have visible focus states and suitable touch targets.
- Respect `prefers-reduced-motion`.
- Test phone, tablet portrait, tablet landscape, laptop and wide desktop breakpoints.
